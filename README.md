# SchoolGraph

基于 Rust + ratatui 的终端图可视化与最短路径计算工具。数据结构课程设计作品。

## 功能

| 视图 | 说明 |
|------|------|
| 场所描述 | 列出所有地点及其介绍 |
| 邻接矩阵 | 表格展示图的邻接矩阵（∞ 表示不可达） |
| 邻接表 | 每个节点的邻居及对应边权 |
| 最短路查询 | 输入起点终点编号，实时显示最短路径与距离，支持 Canvas 可视化、索引映射与详情三种子视图 |
| TSP 回路 | Held-Karp 算法求最优旅行商回路，Canvas 绿色高亮显示 |

> ⚠️ **节点数限制**：TSP 使用状态压缩 DP（Held-Karp），时间复杂度 O(n²·2ⁿ)，空间 O(2ⁿ·n)。推荐节点数 **≤ 16**，最大不超过 18。Canvas 可视化在超过 20 节点时也会变得拥挤。

## 运行

> ⚠️ **`-f` 参数是必须的。** 不提供数据文件程序会退出。`-f` 后面紧跟文件路径，中间有空格。

```bash
# 编译
cargo build --release

# 运行（默认使用 Floyd-Warshall 全源最短路径）
cargo run --release -- -f input.txt

# 使用 Dijkstra 替代 Floyd（通过环境变量 DJ 控制）
DJ=TRUE cargo run --release -- -f input.txt
```

生成的可执行文件位于 `target/release/schgraph`，可直接分发运行：

```bash
./schgraph -f input.txt
```

## 数据文件格式

文件以空白符（空格、换行）分隔字段，严格按以下顺序：

```
<节点数 N>
<节点0名称> <节点0描述>
<节点1名称> <节点1描述>
<节点2名称> <节点2描述>
...（共 N 对）
<边数 M>
<起点名称> <终点名称> <权值>
...（共 M 行）
```

> ⚠️ **节点名称不可重复**——边信息通过名称匹配节点，同名节点会导致映射错误。

### 完整示例

```
3
图书馆 学校图书馆，位于中心区
食堂 学生第一食堂
教学楼 主教学楼
3
图书馆 食堂 200
食堂 教学楼 150
图书馆 教学楼 300
```

此例定义了一个 3 节点的图：图书馆 ↔ 食堂（200）、食堂 ↔ 教学楼（150）、图书馆 ↔ 教学楼（300）。

项目自带 `input.txt` 为 16 节点校园拓扑数据，可作为参考。

|------|------|
| `j` / `↓` | 菜单向下 / 选中项下移 |
| `k` / `↑` | 菜单向上 / 选中项上移 |
| `Enter` / `Tab` | 确认选择 |

| `h` / `l` | 最短路视图中切换子视图 |

## 算法

程序在初始化时计算全源最短路径，支持两种算法，通过环境变量 `DJ` 切换：

| 环境变量 | 算法 | 复杂度 | 说明 |
|----------|------|--------|------|
| `DJ` 未设置或 `FALSE` | **Floyd-Warshall**（默认） | O(n³) | 动态规划，适合稠密图 |
| `DJ=TRUE` | **多源 Dijkstra** | O(n·(m+n)log n) | 对每个源点跑优先队列优化的 Dijkstra，适合稀疏图 |

两种算法结果一致——均填充 `shortest` 矩阵和 `pre` 前驱矩阵，后续路径查询和 TSP 不受影响。

- **Held-Karp TSP**：状态压缩 DP，O(n²·2ⁿ)，`u64::MAX / 2` 作无穷大避免加法溢出。DP 在最短路径矩阵上运行（支持不完全图），路径通过前驱追溯和逐段展开重建

## 项目结构

```
src/
├── main.rs                  # 入口，命令行参数解析
├── lib.rs                   # 库根
└── base/
    ├── mod.rs               # 模块声明
    ├── app.rs               # App 状态、事件循环、文件装配
    ├── events.rs            # 事件通道（mpsc），独立线程 poll
    ├── filescanner.rs       # 文件分词解析器
    ├── graph.rs             # 图数据结构，Floyd-Warshall，Held-Karp TSP
    ├── tui.rs               # 终端初始化/恢复
    ├── update.rs            # Action 枚举 + 按键→操作翻译
    └── ui/
        ├── mod.rs           # View 路由 + 渲染分派
        ├── main_menu.rs     # 主菜单
        ├── place_desc.rs    # 场所描述
        ├── adj_matri.rs     # 邻接矩阵
        ├── adj_list.rs      # 邻接表
        ├── shortest_path.rs # 最短路查询（输入控件 + Canvas + 详情）
        └── tsp.rs           # TSP 回路展示
```
